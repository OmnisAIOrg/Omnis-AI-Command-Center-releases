# Omnis AI Command Center releases

This repository holds **release assets only**: the signed installers for Omnis AI Command Center
and the feed the app reads to update itself. There is no source code here, and issues and pull
requests are not monitored.

## Download

- **Mac** (Apple Silicon and Intel): [CommandCenter-mac.dmg](https://github.com/OmnisAIOrg/Omnis-AI-Command-Center-releases/releases/latest/download/CommandCenter-mac.dmg)
- **Windows**: [CommandCenter-windows.exe](https://github.com/OmnisAIOrg/Omnis-AI-Command-Center-releases/releases/latest/download/CommandCenter-windows.exe)

These links always point at the newest release.

Command Center opens for people whose firm has been given it in the Omnis Console. Sign in with
your Omnis account when the app asks.

## Why this repository is public

The app checks this repository for updates without signing in, which only works on a public
repository. Releases are built, signed and published by CI from the private source repository.
